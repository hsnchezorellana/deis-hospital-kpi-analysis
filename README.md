# 📂 Proyectos Destacados

## 🏥 Dashboard de Egresos Hospitalarios — DEIS Chile 2024

Proyecto de análisis hospitalario desarrollado utilizando SQL, Python y Power BI para evaluar indicadores clínicos y operacionales relacionados con egresos hospitalarios en Chile.

### 🔹 Principales actividades

* Procesamiento y análisis de más de 100.000 registros clínicos.
* Limpieza y validación de datos hospitalarios.
* Transformación y modelamiento de datos mediante Power Query.
* Construcción de KPIs utilizando DAX.
* Desarrollo de dashboards interactivos para análisis de gestión hospitalaria.

### 📊 KPIs desarrollados

* Total de egresos hospitalarios.
* Estancia promedio.
* Hospitalizaciones prolongadas (>7 días).
* Distribución por previsión.
* Egresos por establecimiento.
* Estancia promedio por diagnóstico.
